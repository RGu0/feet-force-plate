# 报告文案 V1

## 使用范围

本页是 FeetForcePlate 报告预览和 PDF 的客户可见文案基线。产品定位为健康筛查、风险提示与专业分析工具；本地基础分析和 V1 回放均不得输出诊断、治疗建议、临床参考范围比较或未来跌倒概率。

正式的 `VALIDATED_RELEASE` 筛查结论须另外满足标准物理输入、参考样本与产品/临床验证门槛。本页不授权将当前 DO-P4864 候选力、回放夹具或本地相对指标写成个人风险等级。

## 图表标题

基础报告使用“相对压力热图”；不把内部空白区称为“COP 轨迹 / 载荷曲线（图表占位）”。当该项目尚未在报告中获批时，统一显示“稳定性轨迹和载荷曲线：当前基础报告不显示”。
