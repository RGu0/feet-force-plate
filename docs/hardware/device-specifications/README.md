# 硬件设备规格书

本目录保存由硬件标准化层读取的、版本化的设备规格书。规格书是设备相关参数的唯一配置入口；算法层不读取这些文件。

每份规格书必须声明：

- 设备和适配器版本，以及已解码原始值的单位；
- 实际逐点板面几何和坐标系；
- 空载基线规则、载荷标定配置和质量策略版本；
- 只读的物理区域尺寸、已验证状态及证据等级。

不得在规格书中保存 COP、轨迹、速度、RMS、评分、报告或其他算法层二级特征。每次改变设备参数、几何或校准配置都必须发布新的规格书版本，保留旧版本以支持历史会话重算。

`estimated-force-session/1.0` 是算法层消费的筛查估计力信息；原始计数、空载基线和曲线实现仅存在于硬件层。尚未获得冻结筛查曲线的规格书必须使硬件层返回 `DEGRADED/UNSUPPORTED`，不得生成产品筛查输入。
