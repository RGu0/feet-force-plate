# FeetForcePlate Windows 便携版使用说明

## 适用范围

本说明适用于经发布负责人签名并提供 SHA-256 摘要的 Windows x86_64 便携 ZIP。
未签名或标记为 `unsigned-development` 的 ZIP 仅供内部测试，不能交付给机构用户。

## 安装前准备

1. 使用 Windows 10/11 x86_64，预留足够磁盘空间并取得机构提供的账号、License 与网络配置。
2. 从发布负责人提供的受控渠道下载 ZIP、同名 `.sha256` 文件与本说明。
3. 按机构 IT 要求核验 ZIP 的 SHA-256；不一致时停止使用并联系项目负责人。
4. 将 ZIP 解压到用户拥有写入权限的本地目录，例如 `C:\FeetForcePlate`。不要在压缩包内直接运行，也不要放入云同步目录或网络共享目录。

## 首次启动

1. 打开解压后的 `FeetForcePlate` 文件夹，双击 `FeetForcePlate.exe`。
2. Windows 显示发布者信息与文件签名正常后再继续；若出现未知发布者或签名警告，停止使用并联系项目负责人。
3. 按机构交付的配置完成登录和 License 验证。未取得机构配置、无法联网或 License 无效时，不得开始正式检测。

## 设备与驱动

设备使用 CH340 USB 转串口驱动。软件会在启动检查中提示设备是否就绪。

- 仅使用机构批准、来源可追溯的 CH340 驱动安装程序。
- 驱动安装可能需要管理员权限，必须由操作者或机构 IT 人员确认后执行；发布 ZIP 和应用程序均不得静默安装驱动。
- 连接设备后先完成启动检查。检查失败时记录界面错误编号，并联系项目负责人或机构指定技术支持。

## 数据、更新与移除

- 解压目录只包含应用程序；检测数据、日志和配置保存在 Windows 的应用数据目录，不应依赖 ZIP 目录保存。
- 删除解压目录只会移除应用程序，不等于删除业务数据。删除任何本地数据前，须按机构的数据保留和授权流程执行。
- 便携版更新时停止应用，将新版本解压到新的空目录，并由发布负责人完成摘要、签名、登录、设备与报告冒烟检查后切换使用。
