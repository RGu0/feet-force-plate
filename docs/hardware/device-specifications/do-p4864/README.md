# DO-P4864 规格书 1.0

机器可读取配置：[1.0.json](1.0.json)。该文件是 DO-P4864 标准化适配器的参数来源。

## 已声明参数

- 坐标系：`BOARD_TOP_LEFT_X_RIGHT_Y_DOWN`；左上首点 `(0, 0) mm`。
- 几何：48 行 × 64 列，列主序源索引，X/Y 点间距均为 `7.99 mm`。
- 用户实测采用的感应区外形：宽约 `509.3 mm`、高约 `381.3 mm`。
- 已解码值：`uint8_count`、`uint8`、列主序；checksum 为观察性质量标志，不作硬性丢帧条件。
- 空载基线：最短 5 秒；用于逐点零偏和噪声参考。
- 载荷模型（首版固定候选）：先按 `V = code / 255 × 4.096` 还原 ADC 电压，
  再使用空载校正后的 `ΔV = max(V - Vzero, 0)`。令
  `u = ln(ΔV / (4.096 - ΔV))`，按下式得到逐点候选法向力：

  ```text
  F_point_N = exp(
    -0.416054290108397
    + exp(-2.057009203457983) × min(u, -0.6755514186685658)
    + exp(-0.5532326211611178) × max(u + 0.6755514186685658, 0)
  )
  ```

  这是 A、B 两组 4.5–8.0 kg 砝码作为同一训练集合、逐条留一后选出的连续双斜率单调曲线（合并留一 MAE `4.690%`）。真人数据未参与选曲；69.8 kg 真人重放的双脚为 `68.793 kg`（`−1.443%`），单脚为 `56.791 kg`（`−18.638%`）。3.5 kg 仍处于起响应区，不适用于该模型。

  校准积分时暂将单个传感点视为直径 `6 mm` 的圆形。先以该面积将逐点候选力换成离散候选压强，在活动点和零压边界之间作双线性插值，再按实际板面坐标积分得到总候选力。该圆形面积仅为当前校准假设，尚不写入对算法的已验证 `active_area_mm2`。

  `ΔV <= 0` 输出 `0 N`；`ΔV >= 4.096 V` 是饱和/无效域，不计算无穷大力值。该模型输出单位为 N，并以冻结的 `MVP_SCREENING_ESTIMATED_V1` 保存为 `estimated_force_n`，供非医疗筛查计算；重复、跨点和温度验证是未来高精度研究，不改变当前产品口径。

## 证据边界

供应商图中“6 mm × 6 mm 感应点”只作为名义资料，未被列为 `active_area_mm2`，也不能用于 Pa 或 N 的推导。3072 点、列主序、8-bit 原始值和约 48.38 ms 主机到达间隔是当前重复采集观察；它们不等价于额定载荷、有效面积、时间精度或跨设备一致性验证。
