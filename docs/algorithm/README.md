# FeetForcePlate 算法设计资料

本目录保存 FeetForcePlate 面向 60 岁及以上人群的静态平衡筛查算法设计、指标定义、评分规则和临床依据。

## 当前设计基线

- 协议版本：`static-balance-fall-screen/1.0`
- 设计状态：已完成产品方案确认，尚未完成算法实现、设备标定、参考人群建模和前瞻性临床验证
- 产品定位：养老机构和社区的初步健康筛查与风险提示，不用于疾病诊断，不输出未来跌倒概率
- 测试动作：双足并拢睁眼 20 秒、双足并拢闭眼 20 秒、固定向左转 90°、左脚在前半串联睁眼 20 秒、右脚在前半串联睁眼 20 秒
- 有效采集时间：80 秒；站位转换、安全确认和每段开始前的稳定等待不计入 80 秒
- 最终结果：综合筛查评分 0–100、低/中/高风险提示、风险依据、动作完成情况、压力板核心指标和后续建议

## 解释边界

客户报告中的 0–100 分是版本化的“综合筛查评分”，不是临床量表原始分，也不是跌倒概率。算法先根据明确高风险背景、动作完成程度和压力指标确定低/中/高风险，再把分数限制在相应区间内；任何正常的单次压力板表现都不能抵消已经成立的高风险事实。

当前硬件接口以 [`docs/通信接口设计文档.md`](../通信接口设计文档.md) 为准：48×64、`uint8` 紧凑帧、实测约 20.7 Hz、列优先映射。原始值语义、物理单位和标定仍未确认，因此未经验证前只允许使用归一化相对指标，不得把结果表述为 N、Pa、kg 或已经验证的物理 COP。
