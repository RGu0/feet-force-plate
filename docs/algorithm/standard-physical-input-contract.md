# 标准物理输入契约

本文件保留为算法文档的稳定入口；V1 的字段、文件格式和责任矩阵以 [硬件层到算法层的标准压力信息流 V1](physical-input-interface-v1.md) 为规范正文。

## 统一口径

硬件层输出唯一标准压力信息流：

```text
physical-pressure-session/1.0
  = 每点板面坐标（mm）
  + 每点法向载荷（N）
  + 每帧实际时间（s）
  + 几何/面积、质量、标定、不确定度和版本
```

硬件层不输出 COP、位移、速度、RMS、步态、风险或报告特征。算法层从板面坐标、载荷、实际时间和四阶段姿态元数据计算所有压力特征；通信层负责加解密、签名、重试和对象存储。

## 算法输入边界

- 坐标是板面物理坐标，算法按阶段姿态归一化为受试者 ML/AP；
- 载荷必须具有明确的法向力 N 语义；原始计数或相对载荷不得伪装为 N/Pa；
- 时间必须来自实际单调时钟，不得按名义采样率补帧；
- 几何、载荷、坐标、时间和测量一致性状态必须显式版本化；
- 动作完成状态由工作流透传，技术无效不自动等同于受试者风险。

## 生产和消费责任

```text
RAY-117 硬件层
  → 板面坐标、法向载荷、时间、质量、版本
算法层
  → 姿态归一化、COP、压力特征、能力门控、风险和报告
通信层
  → 加解密、签名、重试、对象存储和传输状态
```

DO-P4864 的串口、原始计数、48×64、列主序和实测采样事实只属于设备接入/适配器层，不得成为算法分支。

详细规范见 [`physical-input-interface-v1.md`](physical-input-interface-v1.md)。
