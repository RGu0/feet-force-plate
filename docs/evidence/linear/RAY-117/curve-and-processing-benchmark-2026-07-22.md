# RAY-117 响应曲线与数据处理留一验证（2026-07-22）

## 问题与边界

输入的压力–电阻图说明典型压阻元件在低压力区变化快、高压力区趋缓。
但它没有给出本 DP-P4864 每点的实测电阻、分压电路或压力面积，不能直接
作为 ADC 数值的标定表。本实验仅将其用作候选曲线必须**单调**、可检验
**弯曲/饱和**的定性约束。

所有结果来自两组已归档的原始砝码帧：每次留出一个载荷，用其余载荷重新
拟合，再预测留出载荷。原始帧、列主序重排、空载中位数和空间积分不变。

## 候选曲线

设 `V = delta_count / 255 × 4.096`：

1. **固定 V0 幂律**：`F = C × (V / (4.096 − V))^p`，等价于当前公式的
   有效形式。
2. **自由 V0 幂律**：`F = C × (V / (V0 − V))^p`；`V0` 约束为高于当前
   训练帧中最大电压。
3. **双斜率单调曲线**：在 `log(V / (4.096 − V))` 域采用两个正斜率，允许
   有限弯曲但不允许反向。
4. **饱和 Hill 曲线**：单调增加并趋于有限上限。

`R0` 与 `beta` 不独立可辨识：原公式只通过 `10^beta / R0` 使用它们。
因此比较中使用等效增益 `C`，不把任意等价的 `R0`/`beta` 数对误报为硬件
参数。

## 分组留一结果

| 曲线 | A 组原接触面积 MAE | B 组小接触面积 MAE | 结论 |
| --- | ---: | ---: | --- |
| 固定 V0 幂律 | 5.324% | **2.458%** | B 组最佳基线 |
| 自由 V0 幂律 | **1.942%** | 2.689% | 仅 A 组改善，不能跨组复用 |
| 双斜率单调 | 3.943% | 2.748% | 未优于各组最佳 |
| 饱和 Hill | 5.619% | 3.359% | 未获支持 |

A 组自由 `V0` 的各折结果约为 2.40–2.59 V；B 组则在约 4.31–6.00 V
间漂移，且多次触及 6.00 V 搜索上限。这不是稳定的电气 `V0` 估计，不能
替代 ADC 参考电压或设备电路规格。

将两组共同拟合后，最好的双斜率单调曲线 MAE 为 4.690%（其余：固定幂律
7.362%、自由 V0 幂律 6.745%、Hill 7.460%）。它虽不如分组拟合，但按用户
指定的“一条统一曲线”准则，是目前的统一候选。

以全部 A+B 砝码重拟合后的参数（自然对数域）为：

```text
log_gain = -0.4160542901
log_low_slope = -2.0570092035
log_high_slope = -0.5532326212
knot_log_ratio = -0.6755514187
```

令 `z = V / (4.096 − V)`、`u = log(z)`，则：

```text
F_point_N = exp(log_gain
                + exp(log_low_slope) × min(u, knot_log_ratio)
                + exp(log_high_slope) × max(u − knot_log_ratio, 0))
```

真人原始帧**未参与**曲线选择。以这组固定参数重放真实体重 69.8 kg 的
采集，双脚为 68.793 kg（−1.443%），单脚为 56.791 kg（−18.638%）。相较
此前双脚约 60.48 kg、单脚约 54.15 kg 的最佳已记录候选，两个结果均改善，
但单脚仍不足以构成物理力标定验收。

## 结论与下一步

将统一双斜率曲线记录为**当前最佳拟合候选**，但不把它升级为已校准物理
模型。它改善了独立真人双脚重放，仍无法准确重建单脚，说明现有数据首先
缺少对传感器间零偏、增益、接触面积和压力分布的可辨识约束。

后续应优先：

1. 获取电路图/实测 `R` 与 ADC 电压的对应关系，固定物理 `V0`、`R0`，只拟合
   可由数据识别的参数。
2. 使用定位治具与已知接触头，在固定传感器区域做多档、重复加载/卸载，记录
   位置、面积、温度、预热和迟滞。
3. 在多个区域建立逐点零偏和增益图；每点留出载荷用于验证，再评估是否需要
   单独的插值或空间正则化。

在这些条件完成前，所有 `normal_force_n` 均为 `PROVISIONAL`。
